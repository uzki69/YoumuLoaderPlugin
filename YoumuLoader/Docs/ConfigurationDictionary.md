
## YoumuBase

- cookies - cookies file for ytdlp.
- options - default options.
- as_playlist - download as a playlist when on a playlist
- as_audio - download as audio file.
- output - single output for ytdlp -o

## Youtube

- yt_thumbnail_name - youtube thumbnail output for ytdlp -o.
- yt_options - arguments for ytdlp.
- yt_playlist_name - youtube playlist output for ytdlp -o.
- yt_video_name - youtube single video output for ytdlp -o.


## BiliBili
- bb_options - arguments for ytdlp.
- bb_video_name - bilibili video output for ytdlp -o.
